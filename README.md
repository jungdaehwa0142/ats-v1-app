# 상승초입탐지 v1.0

미국 주식의 주간 가격 데이터를 이용해 상승 초입 가능성을 점수화하는 Streamlit 웹앱입니다.

## 반영 분야

- 기술적 분석: 33.33점
- 거래량·수급: 13.33점
- 시장 환경: 6.67점

관측 가능한 총점 53.33점을 100점으로 정규화합니다.

## 점수 기준

- 80점 이상: 강한 상승초입 후보
- 70점 이상: 상승초입 후보
- 60점 이상: 관찰 구간
- 60점 미만: 대기 구간

## 배포 방법

1. 세 파일을 GitHub 저장소 최상단에 올립니다.
2. Streamlit Community Cloud에서 저장소를 연결합니다.
3. Main file path에 `app.py`를 입력합니다.
4. Deploy를 누릅니다.

## 주의사항

학습·연구용이며 투자 권유가 아닙니다. Yahoo Finance 데이터에는 지연, 누락 또는 오류가 있을 수 있습니다.
